# Visual Gallery 0.1.29

Fix existing-tab navigation flashing yellow by activating the tab directly. Increase the gallery heading to 24px by default and add an independent, searchable 18–40px heading-size setting in all 18 languages. Includes the 0.1.27 searchable-settings and local-only PDF hardening.

Validation: production lint, typecheck, tests and local PDF policy gates; disposable macOS Obsidian 1.14.5 integration. No new mobile/Windows or physical-input claims.
