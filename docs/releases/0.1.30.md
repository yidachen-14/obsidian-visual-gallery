# Visual Gallery 0.1.30

Address the 12 source warnings reported for 0.1.29 without changing card geometry
or navigation behavior. Ten settings renderers now explicitly return void; the
icon library uses a synchronous event entry point around its guarded async save.
Enable no-misused-promises and prefer-file-manager-trash-file as build errors.

Grouping rollback now uses FileManager.trashFile for the newly created empty
folder. Retain identity/emptiness checks, collision checks, safe reverse moves,
and partial-failure reporting. Never clean up a folder that contains new content.

Report settings-save failures with translated notices while retaining local edits
for the existing automatic retry. Let explicit saves reject to the UI, with both
save and refresh promises observed immediately. Report cache-clear failures in
settings, restore its button for retry, and retain command-palette error handling.
Icon-save failures remain visible in the picker. New messages cover all 18 locales.

Validation: production lint/typecheck, 629 workspace tests (454 Gallery tests),
plus two PDF local-only policy checks. Failure tests cover save rejection and the
next edit, failed-write recovery on refresh, cache-button recovery/retry, rollback
using the trash API, and preservation of content arriving during rollback.

Native macOS Obsidian 1.14.5 verification in a fresh disposable vault passes:
settings write failure shows a notice, retains the edit and persists it on automatic
retry; cache failure restores its button and retry succeeds; icon failure stays
visible and retry succeeds; an interrupted file grouping restores both originals,
trashes only the newly created empty folder through FileManager, and preserves
unrelated content arriving during rollback. These checks use production handlers
and programmatic DOM events, not physical hardware input. No new mobile/Windows
E2E or card-style changes. Script: scripts/check-review-030-native.mjs.
