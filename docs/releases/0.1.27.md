Visual Gallery 0.1.27 addresses Community review findings while preserving gallery interaction, card geometry and saved appearance.

- Settings are indexed by Obsidian's native settings search. Language changes refresh the definitions and keep saved appearance. The seven sections, icon radios and paired gradient controls remain.
- PDF.js is built for local byte input only. Its networking globals are replaced with explicit denial functions in both the main module and the embedded worker; dynamic compilation is removed in favor of its existing interpreter. Pinned-source checks fail the build if these upstream implementations change. Optional WASM remains disabled. The cache renderer version changes so earlier cached previews are regenerated.
- Native DOM helpers, bound host methods, desktop-only Electron access, window timers, filename validation and saved-data validation address source warnings. List divider CSS retains its fallback in a separate feature-support rule.
- The build gates the review's actionable ESLint rules and PDF policy tests. Tag builds attest all three exact runtime assets before creating an unpublished draft. Existing release assets cannot be overwritten by that workflow.

Base64 data conversion and vault enumeration remain necessary and documented. The optional PDF.js WASM reference remains in upstream library code, but no WASM asset is shipped or enabled and all PDF.js fetch/XHR paths are denied. Malware/obfuscation/network-scan availability is controlled by the Community service. A new Community review is required before claiming a changed public score.
