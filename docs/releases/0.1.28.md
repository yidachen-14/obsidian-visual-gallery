# Visual Gallery 0.1.28 — local candidate

This candidate improves the library workflow and remains local at the user's request.
It includes the unpublished 0.1.27 review remediation; no new official review or
artifact attestation has been issued.

- Customize the sidebar Home label; default to the vault name. Use closed-folder
  and Home defaults while retaining saved custom icons. Choose from a searchable
  registered-icon library with selection feedback and keyboard navigation.
- Bound all three display modes to a preferred page width. Retain preferred card
  widths in wide panes; compress modestly and reduce columns in narrow panes.
- Keep the gallery visible after creating a note or Canvas. Open files in a new
  tab, or activate their existing tab from either gallery or sidebar, including
  concurrent requests and deferred tabs.
- Confirm the whole multi-selection before deletion, even with native prompts
  disabled. Omit single-item Rename and system reveal actions. Create a sibling
  folder containing the selected originals, with collision checks and safe rollback.
- Translate the added settings/actions in all 18 supported interface languages.

Validation: 622 workspace tests / 45 suites, 447 isolated Gallery tests / 29 suites,
plus two PDF policy tests; lint/typecheck and byte-identical offline clean build.
macOS Obsidian 1.14.5 disposable-vault integration and 6,480 host geometry fixture
cases pass. Light/dark normal, selected, hover/focus/drop corners inspected in
all modes. New mobile/Windows behavior and physical input remain unverified.
