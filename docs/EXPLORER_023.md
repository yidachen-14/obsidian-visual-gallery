# 0.1.23 資料夾點擊與展開分離

一般左鍵點資料夾名稱、數量或列空白處：選取資料夾，並讓既有視覺圖庫
跳轉到該位置。展開狀態保持不變，重複點擊也不會切換。
只有點擊左側圖示／箭頭的原生 disclosure 區域才展開或收合，且不跳轉圖庫。
滑鼠離開時仍顯示開啟／關閉資料夾圖示，移入時顯示向下／向右箭頭。

保留原生鍵盤操作及 Command/Ctrl/Shift 等修飾鍵選取。一般檔案仍單擊選取，
雙擊或 Enter 開新分頁；收藏、原生右鍵選單及本機瀏覽狀態維持既有行為。
本次沒有變更卡片 DOM、樣式或圖庫工具列。
