## 本次採用的互動

- 一個共用圖示位置：平時是資料夾，游標移入時是收合／展開箭頭。
- 關閉與開啟資料夾使用不同圖示；箭頭右向代表收合，下向代表展開。
- 頂部顯示主庫名稱與首頁圖示，點擊回到最上層。
- 資料夾右側顯示包含子資料夾的檔案總數，空資料夾顯示 0。

Visual Gallery 使用 Obsidian 原生圖示與既有原生檔案樹，自行實作裝飾層；
沒有搬入參考插件的卡片、搜尋、網路請求或其他功能，也沒有複製其原始碼。
原生的檔案選取、雙擊新分頁、選單與拖移保留。

## 0.1.22 已採用

依使用者確認，加入「常用資料夾收藏／釘選」及「跨裝置設定合併、瀏覽狀態留本機」。
收藏可從原生資料夾選單加入，顯示於首頁下方，支援取消釘選、區段收合與改名／移動追蹤。
共享偏好採逐欄位合併，收藏含取消紀錄；目前位置、篩選、排序、捲動、卡片寬度及樹狀展開
使用裝置本機儲存。實作與驗證範圍見 [EXPLORER_022.md](EXPLORER_022.md)。

## 其他值得考慮

| 功能 | 對 Visual Gallery 的價值 | 建議範圍／代價 |
| --- | --- | --- |
| 圖片快速預覽 | 選取後按空白鍵檢查大圖，避免連開多個分頁 | 優先。先支援本機圖片、Escape 關閉與前後張；不改卡片外觀 |
| 巢狀標籤樹與「未標籤」 | 跨資料夾整理同一主題，提供另一種查找方式 | 次階段。與資料夾目錄切換顯示，需清楚定義多標籤篩選與數量 |
| 可關閉的跟隨模式 | 從編輯器開啟檔案時，自動定位左樹及右側圖庫 | 次階段。預設關閉，避免打斷手動瀏覽；現有原生自動揭示只處理左樹 |
| 搜尋結果送入圖庫 | 搜尋後仍能用現有縮圖挑選結果 | 分階段。先檔名／標籤，再評估全文索引；中文斷詞、重建與大型庫效能需要獨立測試 |

收藏已完成，後續可依「圖片快速預覽 → 標籤樹」評估。這些功能可以降低日常瀏覽成本，
也不需要更換目前的卡片樣式。

## 其他可取之處

- **共享設定與本機狀態分開**：參考插件會合併其他裝置寫入的收藏、圖示與排序；
  目前位置、展開狀態及窗格尺寸留在本機。Visual Gallery 0.1.22 已採用偏好／瀏覽狀態分離，
  原生側欄整體尺寸仍由 Obsidian 管理，沒有加入自訂資料夾排序。
- **資料夾移動後保留個人設定**：收藏、顏色、圖示、自訂順序不能在改名後失聯。
  比單純增加圖示選單更值得優先處理。
- **批次複製 wiki-links**：選取多張卡片後直接複製連結，方便整理索引或素材清單。
- **遞迴檢視子資料夾**：能一次查看某個大分類下的所有內容；必須保留來源路徑、
  控制大量項目渲染，並讓目前檢視模式清楚可見。

## 暫緩直接搬入

- **三種卡片版型／瀑布流**：使用者已明確偏好目前 Visual Gallery 卡片，這次不改。
- **遠端連結預覽、站點圖示、短網址展開**：參考插件的這些模組會向筆記連結的網站、
  Google favicon 服務或社群站點發出請求。與本機素材瀏覽是不同範圍，若日後需要，
  應做成明確可選的獨立功能，而非縮圖載入的預設行為。
- **一次整合全文／PDF 搜尋**：參考插件的 PDF 全文依賴可選 Text Extractor 快取；
  沒有快取時只是檔名搜尋。不能把「支援 PDF 卡片」等同於「已支援 PDF 全文搜尋」。
- **隱藏資料夾**：會與本次「能看見所有檔案」的需求產生取捨；先保留完整目錄，
  真正需要時再提供可恢復且清楚可見的隱藏狀態。
