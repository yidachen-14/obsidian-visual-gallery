# 0.1.22 收藏與狀態合併

資料夾右鍵選單新增「釘選至視覺圖庫」，已釘選者顯示取消釘選。
首頁下方顯示常用資料夾；點擊捷徑定位同一個圖庫，清除當頁暫時篩選，
並保留 Obsidian 原生上一頁／下一頁歷史。Enter／空白鍵可啟用捷徑、
取消釘選及收合區段，不會誤開檔案樹上先前取得焦點的檔案。

收藏捷徑沿用原生資料夾右鍵選單與拖放處理。父資料夾改名／移動會同步
更新其下收藏；明確刪除資料夾會移除相關收藏。同步尚未傳來的資料夾則
保留灰色捷徑，可以取消釘選，不會因另一台尚無此資料夾而自動刪除。

## 儲存邊界

| 共享 | 本機 |
| --- | --- |
| 語言、標題、圖示、漸層、metadata 顯示、預設篩選／排序、收藏 | 目前資料夾、當頁篩選／排序、圖庫捲動、卡片寬度、目錄排序／自動揭示設定、目錄展開與捲動、收藏區收合 |

本機資料使用 Obsidian 的 vault-scoped `App.loadLocalStorage/saveLocalStorage`。
原生目錄展開沿用獨立 tree ID。每個 Gallery view 的 `getState/setState` 仍保留
原生歷史所需的 folder/filter/sort，附上裝置識別供恢復時辨認外來 workspace。
Obsidian 自己的 workspace／全域側欄尺寸仍由主程式管理；外掛沒有改動其同步政策。

舊版 data.json 首次遷移會保留使用者語言、圖示及獨立／舊版共用顏色，
舊 cardWidth 僅在本機尚無記錄時匯入一次。新裝置使用自己的預設卡片寬度。
後續瀏覽、寬度調整及展開收合都不重寫 data.json。

## 共享合併

`data.json` 保留平面偏好供舊版讀取，並含 `_visualGallerySync` 的版本化資料。
`sync-state/<device>.json` 為每台裝置獨立寫入的完整已知共享狀態快照；
本機另有共享資料副本。即使同步工具只傳 data.json，也能合併收藏和偏好。
安裝包不包含任何使用者的 data.json、快照或本機狀態。

每個偏好欄位有單獨的邏輯時間與裝置 ID。不同欄位分別合併；同欄位衝突取
較新的邏輯時間，同時間以裝置 ID 決定一致結果。新修改時間大於已讀取的
最大時間，處理時鐘偏差。收藏使用穩定 ID、路徑與加入順序，取消時保留
刪除紀錄，舊副本回來也不會復活已取消的同筆收藏。同路徑重複收藏合併顯示。

所有讀寫排入單一佇列，寫入前讀取磁碟；收到外部設定事件或每五秒讀取更新。
共享結果相同時不重寫。損壞／未完整傳入的快照會跳過，保留已知資料，
寫入失敗則保留本機副本並重試。尚未重新連線、重新開啟或收到同步檔案的
裝置無法立即收斂；這不是外掛自建的雲端同步服務。

請讓原有的 vault 同步工具傳送本外掛的 data.json，例如啟用社群外掛設定同步。
只有安裝檔同步、沒有設定資料同步時，設定與收藏不會自動跨裝置傳送。
舊版可以讀取平面偏好，但不支援這版的合併協定；各裝置應使用 0.1.22 以上。
