# 0.1.28 圖庫操作改進（本機候選）

2026-10-28。依使用者要求，僅本機開發、驗證及打包，未上架或建立遠端版本。
包含 0.1.27 的 Review 修正；官方重新審查及來源證明仍須等日後發佈流程執行。

## 功能

- 左側頂端首頁按鈕新增「資料庫首頁名稱」設定；空白時顯示資料庫名稱。
- 資料夾卡片預設關閉的資料夾，導航預設首頁。既有儲存的自訂圖示繼續保留。
- 兩個圖示設定改用 Obsidian 完整註冊圖示庫，可搜尋、分批載入、鍵盤移動並顯示目前選項。
  技術圖示 ID 保留原名；常用資料夾、首頁、書本、影像等分類可使用介面語言搜尋。
- 網格、瀑布、列表共用有上限的頁寬：外殼最大 1248px、內容最大 1120px。
  卡片優先維持使用者設定的寬度；窄視窗為容納欄位作有限壓縮，再減少欄數。
  稀疏圖庫維持實際卡片佔用寬度，標題與六個圖示控制保持同列。
- 新建筆記或 Canvas 後留在圖庫並選取新檔。Canvas 寫入合法的空白 JSON。
- 從圖庫卡片及外掛左側檔案列開啟時，先跳到已開啟的同一檔案；否則新建分頁，保留圖庫。
  延遲載入的分頁亦可重用；同時從兩處開啟相同檔案合併為一次操作。
- 多選右鍵刪除顯示整批項目確認框，即使 Obsidian 關閉原生刪除提示仍須確認。
  取消不更動檔案；確定後遵守主程式垃圾桶位置偏好。單選保留原生刪除流程。
- 多選選單不顯示重新命名或 Finder／系統顯示；新增「新增包含所選 X 個項目檔案夾」。
  輸入名稱後將原檔移到目前資料夾內的新資料夾，留在原頁並選取結果資料夾。
  拒絕同名、過期選取及移動期間新出現的目的檔。失敗時嘗試安全還原，絕不覆蓋新出現的檔案；
  若僅完成部分刪除或無法完整還原，顯示數量及錯誤，不宣稱全部成功。
- 新文案提供完整 18 語言字典並核對插值；設定名稱可經原生設定搜尋找到。

## Craft 參考

實際操作 macOS Craft 的網格、瀑布及列表，透過原生視窗選單比較完整寬度與半屏寬度，
再回復原本視窗位置及網格模式。寬畫面卡片維持偏好尺寸，窄畫面減欄並有限壓縮；
列表優先截短名稱／摘要、逐步減少日期欄。亦檢視 Craft 資料夾圖示庫，沒有儲存內容變更。
邊緣拖曳輸入未使 Craft 實際改變大小，因此寬窄比較使用原生視窗控制，不宣稱完成實體拖曳驗證。
只重現觀察到的互動原則，未使用 Craft 程式碼或素材。

## 驗證

- 工作區 production build：622 tests / 45 suites；另 2 個 PDF 本機政策測試；lint、型別檢查通過。
- 獨立、離線 frozen-lockfile 安裝與 production build：447 Gallery tests / 29 suites；另 2 個 PDF 政策測試。
  三個執行檔與工作區逐位元相同。使用 Node 24.22.1；設定的 GitHub Node 22 尚未執行。
- 真正 macOS Obsidian 1.14.5 的一次性資料庫：首頁名稱／圖示、建立後留頁、同檔跨入口與併發重用、
  多選確認／取消／刪除、檔案與資料夾分組及巢狀二進位內容完整性、圖示庫選取與重載保存皆通過。
  三種模式各檢查 2000/1600/1120/980/720/640/475/360/250/180px 視窗寬度；無溢位。
- 既有原生回歸：四欄雙向排序、實際開檔更新瀏覽時間、鍵盤焦點、原生設定滑桿、
  三模式 12/14/22px 字級、重載、metadata、窄畫面欄位、切換模式的捲動錨點均通過。
- 實際主程式 CSS 的幾何 fixture：648 legacy + 5832 Craft = 6480，零失敗。
  包含寬度 180/190/210/220/250/360px、明暗色、12/14/22px、metadata、分數高度與 125%/150% zoom。
  明暗色三模式的普通、選取、hover/focus/drop 截圖逐一檢視，包含底部四角。
  保留單一裁切表面及單一外側描邊；列表維持既有零圓角例外。

原生功能檢查使用 production handler 與程式化 DOM 事件；既有回歸另外使用 Chromium pointer/key input。
拖放狀態截圖使用合成 DragEvent，不代表實體滑鼠/Finder 硬體驗證。幾何 fixture 不是應用程式 E2E。
這一版沒有新增 iOS/Android/Windows 實機驗證；不將先前版本的裝置結果當作本版新功能驗證。
