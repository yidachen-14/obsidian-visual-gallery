# Craft 標題、緊湊列表與欄位排序 — 0.1.26

日期：2026-10-20。使用者明確指出 0.1.25 標題過大、列表列高過高且不應是卡片框，
並要求名稱／上次瀏覽／更新／建立欄位都可切換升降序。本版只修正這些範圍。

## 再次觀察 Craft

在macOS Craft 的同一個資料夾中，透過原生顯示選單從網格切到列表，
觀察同一批文件。列表是透明／平坦橫列、細水平分隔線、小文件預覽、名稱與單行摘要，
右側三個日期欄；沒有每列的圓角卡片框與大陰影。雙倍畫面中的列距約 112 個像素、
標題字高接近 28 個像素，據此估算實作基準約 56px 列高、14px 文字；這是視覺換算，
不是 Craft 內部 DOM 或字體屬性測量。Craft 原生選單顯示目前「上次瀏覽 ↓」。
沒有編輯文件內容或變更排序；研究後恢復原資料夾的網格模式。

## 最終行為

- 文件／資料夾卡片與列表標題預設 14px（原為 17px 卡片）。頁面標題為字級加 1px，
  預設 15px（原為 28px）；標題區 padding 同步收斂，增加預覽空間。
- 原生設定的「卡片版面／標題字級」滑桿可調整 12–22px，即時套用三模式，重載保留。
  依既有欄位合併機制共享；新增設定不重設語言、漸層、圖示或其他偏好。
- 列表預設 56px，沒有列間卡片空隙、正常四面邊框、圓角或浮起陰影。28×34px 的小預覽、
  檔名＋摘要與日期對齊，以細分隔線區別。高字級時列高可略增，避免裁字。
- 名稱／上次瀏覽／更新／建立標題是原生 button，可用滑鼠、Enter、Space 操作。
  再點同一欄反轉順序；新欄位預設名稱 A–Z、日期最近在前。只有作用欄顯示方向箭頭，
  名稱、tooltip、aria-pressed 與焦點同步。原排序選單也提供同一組八個方向選項。
- 上次瀏覽使用本機 file-open 紀錄，不以 mtime 冒充；未瀏覽永遠排在已瀏覽之後，
  同時間以名稱穩定比較，資料夾維持原規則：置頂、A–Z。
  開啟檔案後會更新目前依瀏覽排序的畫面。metadata 關閉時仍保留名稱排序標題；
  窄面板逐步隱藏日期欄。篩選、選取、原生歷史、模式切換和檔案操作共用原路徑。

## 列表幾何例外

選取／焦點／拖入描邊，不加入第二環或布局 border/padding。
